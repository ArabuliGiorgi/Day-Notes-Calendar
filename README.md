DayNotes Calendar წარმოადგენს Android პლატფორმისთვის შექმნილ აპლიკაციას, რომლის საშუალებით მომხმარებელს შეუძლია კალენდარში კონკრეტული დღის არჩევა, 
ამ დღისთვის ჩანაწერების (Notes) დამატება, ნახვა და წაშლა. აპლიკაცია ასევე აჩვენებს თითოეულ დღეზე არსებული ჩანაწერების რაოდენობას და მხარს უჭერს 
როგორც ნათელ (Light), ასევე მუქ (Dark) თემას.

აპლიკაციის მთავარი მიზანია მომხმარებლისთვის ყოველდღიური გეგმებისა და მნიშვნელოვანი ინფორმაციის მარტივად ორგანიზების შესაძლებლობის უზრუნველყოფა.

ძირითადი ფუნქციონალი\
-> კალენდრის ვიზუალური ჩვენება\
-> კონკრეტული დღის არჩევა\
-> არჩეული დღისთვის ჩანაწერების დამატება\
-> ჩანაწერების ნახვა და წაშლა\
-> ყველა ჩანაწერის საერთო სიის ნახვა\
-> თითოეულ დღეზე არსებული ჩანაწერების რაოდენობის ჩვენება\
-> აპლიკაციის ფონის გადართვა (Light/Dark Mode)\
